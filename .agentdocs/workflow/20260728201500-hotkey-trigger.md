# 快捷键触发 UI 功能

## 背景与目标

直播中主播希望按快捷键即时触发 UI 事件（如弹窗弹出、图层显隐），用于点赞飘心、关注提示、广告切入等。要求跨平台，**以 Windows 为主、兼顾 macOS**。

## 约束与原则

- 快捷键由本地服务的全局键盘钩子捕获，复用已有 WebSocket 通道广播，绕开直播软件浏览器源能否接收键盘事件的不确定性。
- 跨平台：Windows 开箱即用；macOS 需辅助功能权限且 Sonoma 可能拦截未签名二进制。
- 钩子失败必须降级，不能影响 HTTP/WS 主链路。

## 关键风险

1. **macOS 钩子不可用**：Sonoma 拦截未签名 uiohook 二进制，即使授权也收不到事件。缓解：降级不致命；`/test-trigger` 端点可在 mac 上验证前端响应；Windows 无此问题。
2. **组合键匹配**：uiohook 的 `e.key` 跨平台不一致（字母大小写、修饰键命名），`hotkey.cjs` 的 `normalize` 做了归一化，但 Windows 真机需实测匹配是否准确。
3. **快捷键冲突**：全局钩子可能与游戏/其他软件冲突，快捷键必须可配置（已支持）。
4. **native 依赖**：`uiohook-napi` 引入预编译二进制，项目不再是纯前端，安装时可能需下载对应平台 prebuild。

## 测试用例

- **服务启动**：`npm run dev`，日志应出现 `[hotkey] 状态: running`（mac）或 Windows 实测。health 含 `hotkey` 字段。
- **配置下发**：POST 含 `hotkeys` 的配置，WS 订阅端收到 `config:update` 且 `payload.hotkeys` 正确。
- **触发链路（mac 用 test-trigger）**：`curl -X POST http://127.0.0.1:3001/test-trigger -H "Content-Type: application/json" -d '{"layerId":"<id>","action":"popup","combo":"Ctrl+Shift+1"}'`，展示页对应 popup 图层应弹出。
- **Windows 真机**：配置一个 popup 图层绑 `Ctrl+Shift+1`，直播中按该组合键，展示页应弹出弹窗。
- **显隐触发**：绑 `toggle` 动作，按键切换图层显隐。
