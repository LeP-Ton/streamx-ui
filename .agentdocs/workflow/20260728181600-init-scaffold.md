# 初始化 streamx-ui 项目骨架

## 背景与目标

用户需要一个纯前端直播 UI 系统 `streamx-ui`，可配置直播内容、特效、弹窗等 UI，营造直播氛围、打造 IP、宣传自媒体频道或广告。通过直播软件的浏览器源加载展示页。**核心诉求：本地使用 + 直播中改配置即时自动生效。** 主要使用抖音直播，需考虑抖音直播助手兼容性。

## 约束与原则

- 纯前端项目（Vite + React + TS）。
- 即时生效需本地 Node 服务当中间人（直播软件浏览器源是独立进程，不共享内存）。
- 兼容性以 OBS 为确定目标；抖音直播助手等闭源软件不假设支持 WebSocket，需实测。
- 架构必须能自动降级，不因 WebSocket 不可用而整体不可用。

## 关键风险

1. **抖音直播助手兼容性未知**：公开资料被搜索过滤，无法确认其网页源是否支持 WebSocket/加载 localhost。缓解：`compat.html` 实测 + 展示页自动降级轮询。
2. **直播软件浏览器源透明背景**：需用户在直播软件里正确开启透明选项，否则展示页背景非透明。文档已提示。
3. **配置画布分辨率**：需与直播软件浏览器源设置一致（默认 1920×1080），不一致会错位。
4. **本地服务进程管理**：目前需手动 `npm run dev` 同时起服务与前端，未来可考虑打包成单一可执行。

## 测试用例

- **安装与启动**：`npm install` 后 `npm run dev`，应同时启动 3001（服务）与 5173（前端）。
- **配置面板**：访问 http://127.0.0.1:5173/，默认显示标题与底部滚动条两个图层；可增删改图层属性。
- **实时推送**：另开标签访问 http://127.0.0.1:5173/overlay.html，在配置面板改文字，展示页应在 ~250ms 内更新。
- **降级验证**：停掉 `npm run dev:server`，展示页状态指示应变为「未连接」；重启服务后恢复。
- **兼容性自测**：访问 http://127.0.0.1:5173/compat.html（需服务在运行），四项检测应全部通过；将该 URL 填入直播软件浏览器源观察 10-30 分钟。
