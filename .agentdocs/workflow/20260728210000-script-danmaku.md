# 剧本人气系统（剧本弹幕）

## 背景与目标

直播冷启动时真人弹幕少，需要按预设剧本自动推送弹幕营造氛围。支持编辑剧本条目（文本/颜色/时机/循环），到点自动推送。**工具能力中立**，内容合规由使用者自行把控。

## 约束与原则

- 复用已有 WS 广播通道，触发源从「快捷键/按键」改为「定时器」。
- 内容中立：调度器只按时间表推文本，不审查、不限制内容。
- 剧本配置随主配置一起 POST，server 重置调度器。

## 关键风险

1. **内容合规**：剧本弹幕属虚构互动数据，平台风控可能识别。文档与面板提示使用者自行把控合规。
2. **调度器生命周期**：进程重启后从 delay 重新计时，不持久化进度。可接受。
3. **弹幕渲染性能**：当前用 DOM + Web Animations API，单条弹幕一个元素，量大时可能占用，初版够用。

## 当前进展

端到端链路打通并经用户肉眼确认：展示页能看到彩色弹幕从右往左飘过。修复了两个真实 bug：
- DanmakuLayer 原用 CSS 变量 `--sx-fly-distance` + keyframes，React 内联 style 设 CSS 变量不可靠，弹幕停在画布外。改用 `element.animate`（Web Animations API）。
- 展示页画布固定 1920x1080 未做视口缩放，本地浏览器右下方超出视口。加 `useFitScale` 等比缩放。

## 代码变更（见 git diff）

- `src/editor/ScriptPanel.tsx`：剧本编辑面板（增删弹幕、delay/interval、总开关）。

- `src/lib/client.ts`：`SubscribeOptions` 新增 `onDanmaku`，WS onmessage 处理 `danmaku` 消息，导出 `DanmakuEvent`。
- `src/overlay/Overlay.tsx`：接 onDanmaku→emitDanmaku，渲染 DanmakuLayer，新增 `useFitScale` 画布缩放。

- `src/assets/animations.css`：新增 `sx-danmaku-fly` keyframes（保留，虽当前改用 WAAPI，但可作降级）。
- `AGENTS.md`：补充 script 模块、DanmakuLayer WAAPI 注意、useFitScale 等认知。

## 测试用例

- **服务启动**：`npm run dev`，health 含 `script` 字段。
- **端到端**：POST 启用剧本配置（`script.enabled:true`，弹幕 delay 1.5/4/6.5s），WS 订阅端应按时机收到对应 danmaku 消息。
- **展示页**：硬刷新 `/overlay.html`，画布上方应有彩色弹幕从右往左飘过。
- **配置页**：`/` 左侧「剧本人气系统」面板可增删弹幕、设 delay/interval（interval>0 循环）、勾选总开关。
- **降级**：`script.enabled:false` 时 server 不发弹幕，展示页无弹幕（不影响图层）。
