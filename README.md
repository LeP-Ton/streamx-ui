# streamx-ui

一个纯前端的直播 UI 系统：通过可视化配置面板编辑直播内容、特效、弹窗等 UI，实时推送到直播软件（OBS / 抖音直播助手等）加载的浏览器源，用于营造直播氛围、打造 IP、宣传自媒体频道或广告。

## 为什么需要本地服务

直播软件的「浏览器源」是**独立进程**，和配置页不共享内存。所以「配置页改了 → 直播间画面立即变」无法靠纯前端的 `localStorage`/`BroadcastChannel` 跨进程完成，需要一个**本地中间人服务**转发消息。

本项目在本地起一个 Node 服务（`127.0.0.1:3001`）：
- **WebSocket**（`ws://127.0.0.1:3001/ws`）：配置改动秒级推送到展示页
- **HTTP 兜底**（`GET /config`）：当直播软件不支持 WebSocket 时，展示页自动降级为定时轮询

## 直播软件兼容性

| 软件 | WebSocket 实时 | 说明 |
|------|---------------|------|
| OBS | ✅ 成熟可靠 | 主目标平台，CEF 完整支持 |
| 抖音直播助手 | ⚠️ 未知 | 闭源魔改，需用本项目自带的 `compat.html` 实测 |

**建议**：先用 `compat.html` 在目标直播软件里跑 10-30 分钟确认能力，再决定是否依赖实时推送。展示页已内置自动降级，不支持 WebSocket 时会退化为轮询，仍能显示内容。

## 快速开始

```bash
cd streamx-ui
npm install
npm run dev
```

启动后：
- 配置面板：http://127.0.0.1:5173/
- 直播展示页（填入直播软件浏览器源）：http://127.0.0.1:5173/overlay.html
- 兼容性自测页：http://127.0.0.1:5173/compat.html

`npm run dev` 会同时启动本地服务（3001）与前端（5173）。

## 在直播软件里使用

1. 启动 `npm run dev`。
2. 在直播软件的「浏览器源 / 网页源」里填入 `http://127.0.0.1:5173/overlay.html`。
3. 宽高设为 1920×1080（与配置画布一致），如需透明背景，勾选浏览器源的「刷新时刷新浏览器」之外的透明选项。
4. 在配置面板（5173）里编辑图层，展示页会实时更新。

## 项目结构

```
streamx-ui/
├─ server/              # 本地 Node 服务（WebSocket + HTTP 兜底）
├─ src/
│  ├─ overlay/          # 展示页（直播软件加载）
│  ├─ editor/           # 配置面板（本地编辑）
│  ├─ components/       # 图层渲染组件
│  ├─ store/            # 配置数据模型
│  ├─ lib/              # 本地服务客户端（含降级）
│  └─ assets/           # 全局动画 CSS
├─ index.html           # 配置面板入口
├─ overlay.html         # 展示页入口
├─ compat.html          # 直播软件兼容性自测页
└─ vite.config.ts       # 双入口 Vite 配置
```

## 技术栈

Vite + React + TypeScript + ws(WebSocket)。无数据库，配置存内存，进程重启需在配置页重新触发一次推送（启动时自动推送默认配置）。
